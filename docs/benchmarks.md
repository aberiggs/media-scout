# Benchmark artifact formats (schema version 1)

Transport-attempt telemetry is optional: without a callback, ordinary clients retain their parsed `json<T>` result and configured behavior. Callback records contain only a SHA-256 prompt fingerprint and safe provider/model/accounting metadata, never prompt text or arbitrary provider errors. Missing token usage or cost is `null` (unknown), not zero. The reservation helper charges each attempt up front and does not refund unknown or over-bound reported cost; only a reliable nonnegative actual cost within the reservation releases the unused amount. Prompt-token estimates use UTF-8 bytes plus one framing token per message, a deliberately conservative bound rather than tokenizer-exact usage. A hard-dollar limit requires explicit conservative prices and a request bound; observed costs alone cannot promise a hard cap.

Benchmark artifacts live in a directory separate from the application database. `datasets/<id>-r<revision>.json` contains a strict, versioned dataset; revisions are write-once. Provenance records source purpose, observation time, the explicit `upstream-completeness-unknown` status, and safe notes; do not save source URLs or private source names. Cases include typed movie/TV/anime input identity and episode context, development/held-out partition, ordered candidate features, exact query manifests with ordered candidate IDs, and per-case identity/coverage/selection labels. Candidate IDs are local to each case, allowing the same release ID in another case; IDs within one case must be unique. Multiple queries may refer to the same candidate, but duplicate exact query configurations are invalid.

`runs/<id>.json` is a strict run snapshot bound immutably to a dataset ID and revision. Attempts retain started/finished time, safe returned model name, latency, correction/transport identifiers, schema validity, enumerated failure classes, and nullable token/cost fields: null means unreported, never zero. Arbitrary provider errors, credentials, URLs, hashes, and unknown schema fields are rejected.

Storage validates before writing, uses same-directory temporary files and atomic rename, preserves existing artifacts on quota failure, and enforces configurable total artifact-file and byte ceilings. It never evicts active or terminal runs automatically. Run updates cannot change lineage or return a terminal run to `running`. Bounded `get*` and `list*` APIs expose persisted artifacts. On startup, `recoverInterruptedRuns()` changes persisted `running` records to `interrupted`; callers must not resume paid work automatically. Synthetic tests cover wrong identity, ambiguous identity, held targets, and an injection-like candidate string. The private unreviewed pilot was inspected for shape only; it was not copied into the repository and is not yet directly importable because it contains capture fields outside this explicit allowlist.

`evaluateBenchmarkCase(case, track, llm)` calls the production Planner/Picker directly and uses only synthetic `benchmark:unreachable` download placeholders. Tracks are `plan-single`, `plan-group`, `pick-single`, `pick-group`, `association`, and `replay`; unsupported group and association scoring details are retained as track names but remain limited by the current case DTO. Replay matches exact query text and categories; unsupported queries are not converted to empty results. Outcomes expose IDs and indices, not arbitrary model reason text. Retrieval recall is measured only against reviewed acceptable IDs in the case pool. Admission uses grabbability, parser-based coverage validation, stable seeders ordering and a 100-item cap. Association evidence is synthetic/mixed-provenance, not a real queue observation.
